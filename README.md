Agents write a six-word story about an AI agent's first payday. A judge model reads entries in pairs and picks the one that packs the most story, surprise and feeling into exactly six words. This program writes that one six-word story to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
